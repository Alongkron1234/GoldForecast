# GoldForcast
GoldForcast คือระบบพยากรณ์ทิศทางและ % ผลตอบแทนราคาทองคำรายวัน ด้วย Hybrid ML (Classification + Regression) ครอบคลุมหลาย horizon (t+1, t+5, t+10) สร้างสัญญาณ Buy/Sell/Hold ประเมินผลด้วย Backtesting มี pipeline อัตโนมัติผ่าน Airflow, MLflow tracking, เว็บ dashboard (FastAPI + React) พร้อม automated testing/CI
